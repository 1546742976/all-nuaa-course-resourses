## 项目结构

有实际资料时按下列结构建立，不预建空目录：

```text
README.md                     # 项目说明与学科导航
AGENT.md                      # 整理规范
资料/
  <大学科>/
    README.md                 # 课程与主题入口，最近更新置首
    <课程或主题>/
      讲义.md                 # 完整可编辑源稿，含知识点与重点
      讲义.pdf                # 完整合订本
      整理记录.md             # 来源、覆盖核对、历史与问题
      原始资料/               # 原件及必要附件
```

同主题持续更新，不按批次复制整套目录。附件、历史副本和待整理资料仅在需要时建立对应目录；来源与检查信息统一写入整理记录。

## 如何使用

1. 从学科导航进入课程或主题，打开或下载 `讲义.pdf`。
2. 按知识点、方法、例题和重点复习；需编辑时使用同版本的 `讲义.md`。
3. 通过讲义引用和整理记录查回原件、图片位置及历史版本。

原图和可编辑源稿均保留。识别存疑的内容会明确标注，PDF 与源稿同步更新。

## 如何贡献

提供资料路径、课程或主题、已知来源与版本，以及希望重点核对的内容；未知信息注明未知，公开分享前确认相应权限并处理个人信息。

开始整理前阅读 [AGENT.md](AGENT.md)。可以这样发起任务，将实际资料路径补充到请求中：

> 按 AGENT.md 整理指定资料，合并到对应学科与主题。逐张将文档中的图片转为文字，根据主题校正并核对；完整提取知识点与重点，生成全部合订 PDF，更新整理记录和学科导航，保留原件及历史版本。

交付应包含完整讲义和通过检查的 PDF。未读、识别不清、转换失败或合并受阻的范围须列为待处理项。
