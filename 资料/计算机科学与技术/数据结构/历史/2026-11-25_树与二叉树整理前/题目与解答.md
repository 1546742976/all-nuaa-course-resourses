## 绪论

<a id="p-9101"></a>
### P-9101｜基本概念辨析

**知识点：** [K-9101](讲义.md#k-9101)、[K-9102](讲义.md#k-9102)。**考点：** 数据、数据元素、数据项、数据对象、数据结构、逻辑结构、存储结构和抽象数据类型。**题型：** 简答题。**来源：** B007-01 第 21 张。

简述上述八个概念。

**解：** 数据是能够输入计算机并由程序处理的信息表示；数据元素是通常作为整体处理的基本单位；数据项是元素中具有独立含义的组成部分；数据对象是性质相同的数据元素的集合。数据结构是元素及其关系；逻辑结构描述元素的逻辑关系；存储结构是数据及关系在计算机中的表示。抽象数据类型由数据对象、对象间关系和对象上的操作共同描述，独立于具体实现。

<a id="p-9102"></a>
### P-9102｜元素的共同特征

**知识点：** [K-9101](讲义.md#k-9101)。**考点：** 同一逻辑结构中元素的类型特征。**题型：** 单项选择。**来源：** B007-01 第 22 张第 2 题。

通常要求同一逻辑结构中的所有数据元素具有相同特性，这意味着什么？

A. 数据具有同一特点。  
B. 不仅元素所包含的数据项个数相同，而且对应数据项的类型一致。  
C. 每个数据元素都一样。  
D. 数据元素所包含的数据项个数相等。

**解：** 课件选 B：这里说的是元素的组成与对应类型一致，并非每个元素的值相等；D 只说个数，遗漏对应类型。

<a id="p-9103"></a>
### P-9103｜相同逻辑结构

**知识点：** [K-9101](讲义.md#k-9101)、[K-9102](讲义.md#k-9102)。**考点：** 区分数据项、元素和逻辑关系。**题型：** 单项选择。**来源：** B007-01 第 22 张第 3 题。

以下说法正确的是哪项？

A. 数据元素是数据的最小单位。  
B. 数据项是数据的基本单位。  
C. 数据结构是带有结构的各数据项的集合。  
D. 一些表面上很不相同的数据可以有相同的逻辑结构。

**解：** 选 D。例如学生排队与任务队列的内容不同，却都可用线性关系描述。元素通常是整体处理的基本单位，数据项组成元素；数据结构侧重数据元素之间的关系。

<a id="p-9104"></a>
### P-9104｜影响时间复杂度的因素

**知识点：** [K-9104](讲义.md#k-9104)。**考点：** 规模与输入初态。**题型：** 单项选择。**来源：** B007-01 第 23 张第 4 题。

算法的时间复杂度取决于：A. 问题规模；B. 待处理数据的初态；C. 计算机配置；D. A 和 B。

**解：** 按课件题目选择 D。同一规模下，实际基本操作次数还可能随数据排列变化，因而有最好、最坏与平均情况之分。大 O 的渐近分析通常抽象掉机器常数；实际运行时间仍受计算机配置影响。

<a id="p-9105"></a>
### P-9105｜双重循环

**知识点：** [K-9104](讲义.md#k-9104)。**考点：** 嵌套循环计数。**题型：** 算法分析。**来源：** B007-01 第 23 张第 5 题。

求下列程序段的时间复杂度：

```c
s = 0;
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        s += B[i][j];
        sum = s;
    }
}
```

**解：** 外层执行 `n` 次，每次内层也执行 `n` 次，循环体执行 `n²` 次，因此时间复杂度为 `O(n²)`。

<a id="p-9106"></a>
### P-9106｜每次乘三

**知识点：** [K-9104](讲义.md#k-9104)。**考点：** 几何增长循环计数。**题型：** 算法分析。**来源：** B007-01 第 24 张第 6 题。

设 `n≥1`，求时间复杂度：

```c
i = 1;
while (i <= n) {
    i = i * 3;
}
```

**解：** 第 `k` 次循环开始时 `i=3^(k−1)`；循环次数是 `floor(log₃ n)+1`，故为 `O(log n)`。课件记作 `O(log₃ n)`，底数只改变常数因子。

<a id="p-9107"></a>
### P-9107｜逐行缩短的循环

**知识点：** [K-9104](讲义.md#k-9104)。**考点：** 等差求和。**题型：** 算法分析。**来源：** B007-01 第 25 张第 7 题。

求下列程序段的时间复杂度：

```c
x = 0;
for (i = 1; i < n; i++) {
    for (j = 1; j <= n - i; j++) {
        x++;
    }
}
```

**解：** 外层 `i=1` 时内层执行 `n−1` 次，依次减少至 1 次，共 `n(n−1)/2` 次，所以是 `O(n²)`。

<a id="p-9108"></a>
### P-9108｜平方根循环

**知识点：** [K-9104](讲义.md#k-9104)。**考点：** 根据循环条件反推执行次数。**题型：** 算法分析。**来源：** B007-01 第 26 张第 8 题。

设 `n>1`，在乘法不会溢出的数学计数模型下，求时间复杂度：

```c
x = n;
y = 0;
while (x >= (y + 1) * (y + 1)) {
    y++;
}
```

**解：** 每轮 `y` 加 1，当下一次的平方大于 `n` 时停止。循环执行 `floor(√n)` 次，因此时间复杂度是 `O(√n)`；实际程序必须选择能够容纳平方运算的整数类型。

## 线性表

<a id="p-9109"></a>
### P-9109｜顺序表地址

**知识点：** [K-9106](讲义.md#k-9106)。**考点：** 用首地址和位序计算元素地址。**题型：** 单项选择。**来源：** B007-02 第 20 张第 1 题。

顺序表第一个元素的地址为 100，每个元素长度为 2，第 5 个元素地址是：A. 110；B. 108；C. 100；D. 120。

**解：** 选 B。第 5 个元素之前有 4 个元素，地址是 `100+4×2=108`。

<a id="p-9110"></a>
### P-9110｜顺序表常数时间操作

**知识点：** [K-9106](讲义.md#k-9106)。**考点：** 区分随机访问和元素移动。**题型：** 单项选择。**来源：** B007-02 第 20 张第 2 题。

在有 `n` 个结点的顺序表中，哪项操作的时间复杂度为 `O(1)`？

A. 访问第 `i` 个结点（`1≤i≤n`）和求第 `i` 个结点的直接前驱（`2≤i≤n`）。  
B. 在第 `i` 个结点后插入新结点（`1≤i≤n`）。  
C. 删除第 `i` 个结点（`1≤i≤n`）。  
D. 将 `n` 个结点从小到大排序。

**解：** 按题目的一般最坏情况选 A：合法下标可直接定位，前驱位序是 `i−1`。插入和删除最坏要移动线性数量的元素，末尾位置可能不需要移动。

<a id="p-9111"></a>
### P-9111｜插入平均移动次数

**知识点：** [K-9106](讲义.md#k-9106)。**考点：** 在等概率插入位置下求平均值。**题型：** 单项选择。**来源：** B007-02 第 21 张第 3 题。

向有 127 个元素的顺序表插入一个新元素并保持原顺序，平均移动几个元素？A. 8；B. 63.5；C. 63；D. 7。

**解：** 按课件将 128 个插入位置视为等概率，选 B。各位置移动数量依次为 127、126、…、0，平均是 `(127+0)/2=63.5`；若各位置概率不同，平均数需按实际概率加权。

<a id="p-9112"></a>
### P-9112｜链表的适用场景

**知识点：** [K-9107](讲义.md#k-9107)、[K-9108](讲义.md#k-9108)。**考点：** 插入删除的指针操作与定位成本。**题型：** 单项选择。**来源：** B007-02 第 21 张第 4 题。

线性表 `L` 在什么情况下适合用链式结构？

A. 需经常修改结点值。  
B. 需不断对 `L` 进行删除插入。  
C. `L` 中含有大量结点。  
D. `L` 中结点结构复杂。

**解：** 按课件选 B。链表在已知操作位置的前驱时，不必像顺序表那样整体移动后续元素；如果每次只给位序，仍需考虑寻找前驱的时间。

<a id="p-9113"></a>
### P-9113｜两个有序表的最少比较次数

**知识点：** [K-9105](讲义.md#k-9105)、[K-9108](讲义.md#k-9108)。**考点：** 标准双指针归并的最好情况。**题型：** 单项选择。**来源：** B007-02 第 21 张第 5 题。

将两个各有 `n` 个元素的有序表归并为一个有序表，最少比较次数为：A. `n`；B. `2n−1`；C. `2n`；D. `n−1`。

**解：** 在 `n≥1` 且使用逐元素双指针归并的题设下选 A。若第一表所有元素都小于第二表，比较 `n` 次后第一表用尽，直接接上第二表剩余部分。标准方法最坏可需要 `2n−1` 次比较。

<a id="p-9114"></a>
### P-9114｜线性表的直接前驱与后继

**知识点：** [K-9105](讲义.md#k-9105)。**考点：** 首尾、空表和顺序概念。**题型：** 单项选择。**来源：** B007-02 第 22 张第 6 题。

线性表 `L=(a₁,a₂,…,aₙ)`，哪种说法正确？

A. 每个元素都有一个直接前驱和一个直接后继。  
B. 线性表中至少有一个元素。  
C. 表中元素必须按值从小到大或从大到小排列。  
D. 除第一个和最后一个元素外，其余每个元素都有一个且仅有一个直接前驱和一个直接后继。

**解：** 选 D。`n=0` 可以是空表；非空表的首元素没有直接前驱，末元素没有直接后继；元素的位序不要求按数值大小排列。

<a id="p-9115"></a>
### P-9115｜顺序表插入要移动多少元素

**知识点：** [K-9106](讲义.md#k-9106)。**考点：** 插入位置和边界。**题型：** 单项选择。**来源：** B007-02 第 23 张第 7 题。

在长度为 `n` 的顺序表中，在第 `i` 个元素之前插入新元素（`1≤i≤n+1`），需向后移动多少个元素？A. `n−i`；B. `n−i+1`；C. `n−i−1`；D. `1`。

**解：** 选 B。需要移动第 `i` 至第 `n` 个元素，共 `n−i+1` 个；当 `i=n+1` 时在表尾插入，移动 0 个。

<a id="p-9116"></a>
### P-9116｜创建有序单链表的复杂度

**知识点：** [K-9108](讲义.md#k-9108)。**考点：** 建表方法与输入顺序对复杂度的影响。**题型：** 单项选择与条件辨析。**来源：** B007-02 第 23 张第 8 题。

创建包含 `n` 个结点的有序单链表，时间复杂度为：A. `O(1)`；B. `O(n)`；C. `O(n²)`；D. `O(n log₂ n)`。

**解：** 课件选 C，依据是依次处理待插入元素，每次从表头查找有序插入位置，最坏比较次数为 `0+1+…+(n−1)=O(n²)`。但原题没有说明输入是否已排序以及建表方法：若输入本来有序且维护尾指针，可在 `O(n)` 时间建表。因此 C 是课件指定方法下的最坏情况，单凭题面无法唯一确定。

<a id="p-9117"></a>
### P-9117｜顺序存储与链式存储

**知识点：** [K-9106](讲义.md#k-9106)、[K-9107](讲义.md#k-9107)。**考点：** 两种实现的访问与空间特点。**题型：** 单项选择。**来源：** B007-02 第 24 张第 9 题。

以下说法错误的是：

A. 求表长、定位这两种运算采用顺序存储实现时，效率不比采用链式存储时低。  
B. 顺序存储的线性表可以随机存取。  
C. 顺序存储要求连续存储区域，因此存储管理不够灵活。  
D. 线性表的链式存储结构优于顺序存储结构。

**解：** 课件选 D。链式与顺序结构各有适用场合，不能笼统断言一种总优于另一种。A 也依赖具体实现：例如顺序表和链表都可额外维护长度，而是否能随机定位还取决于访问模型。

<a id="p-9118"></a>
### P-9118｜插入结点的两句指针操作

**知识点：** [K-9108](讲义.md#k-9108)。**考点：** 正确连接新结点及原后继。**题型：** 单项选择。**来源：** B007-02 第 25 张第 10 题。

在单链表中，要将 `s` 所指结点插入到 `p` 所指结点之后，选择正确语句：

A. `s->next=p+1; p->next=s;`  
B. `(*p).next=s; (*s).next=(*p).next;`  
C. `s->next=p->next; p->next=s->next;`  
D. `s->next=p->next; p->next=s;`

**解：** 选 D。先将旧后继保存到 `s->next`，再让 `p` 指向 `s`。B 先覆盖了旧后继，随后让 `s` 指向自身；C 则未把 `s` 接到 `p` 后面。A 的 `p+1` 不能用作链表下一结点的通用地址。

## 栈与队列

<a id="p-9119"></a>
### P-9119｜判断不可能的出栈序列

**知识点：** [K-9109](讲义.md#k-9109)。**考点：** 栈的后进先出与交替操作。**题型：** 单项选择。**来源：** B007-03 第 20 张第 1 题。

元素 1、2、3、4、5 依次进栈，哪一种出栈序列不可能出现？

A. 5，4，3，2，1；B. 2，1，5，4，3；C. 4，3，1，2，5；D. 2，3，5，4，1。

**解：** 选 C。4、3 出栈之后，1 和 2 都已经入栈，且 2 在 1 上方，必须先出 2 才能出 1。

<a id="p-9120"></a>
### P-9120｜首个出栈元素是 n

**知识点：** [K-9109](讲义.md#k-9109)。**考点：** 根据首个输出反推栈中内容。**题型：** 单项选择。**来源：** B007-03 第 21 张第 2 题。

入栈序列是 `1,2,3,…,n`，出栈序列为 `p₁,p₂,…,pₙ`，若 `p₁=n`，则 `pᵢ` 为：A. `i`；B. `n−i`；C. `n−i+1`；D. 不确定。

**解：** 选 C。要首先取出 `n`，前面的元素必须都已入栈且尚未出栈；之后只能依次取出 `n,n−1,…,1`。

<a id="p-9121"></a>
### P-9121｜循环队列的不同指针约定

**知识点：** [K-9111](讲义.md#k-9111)。**考点：** 队头前一位置和队尾位置的长度公式。**题型：** 单项选择。**来源：** B007-03 第 21 张第 3 题。

数组 `Q[n]` 表示循环队列，`f` 为当前队头元素的前一位置、`r` 为队尾元素位置，队列元素个数小于 `n`。元素个数为：A. `r−f`；B. `(n+f−r)%n`；C. `n+r−f`；D. `(n+r−f)%n`。

**解：** 选 D。队列沿环从 `f` 后一个位置到 `r`，两位置之差取模；加 `n` 后取模可处理下标绕回。这里的 `f、r` 与讲义中 `front` 指向队头、`rear` 指向尾后位置的约定不同。

<a id="p-9122"></a>
### P-9122｜栈连接队列的最小容量

**知识点：** [K-9109](讲义.md#k-9109)。**考点：** 由队列输出反推栈输出和最大同时在栈数。**题型：** 单项选择。**来源：** B007-03 第 22 张第 4 题。

空栈 `S` 和空队列 `Q` 中，`e₁…e₆` 依次进入栈；每个出栈元素立即入队。若出队顺序为 `e₂,e₄,e₃,e₆,e₅,e₁`，栈容量至少是多少？A. 2；B. 3；C. 4；D. 6。

**解：** 选 B。队列先进先出，所以出栈顺序与给出的出队顺序相同。先入 `e₁,e₂`、出 `e₂`；再入 `e₃,e₄`、依次出 `e₄,e₃`；再入 `e₅,e₆`、依次出 `e₆,e₅,e₁`。栈中最多同时有 3 个元素，而在 `e₄` 入栈时必须同时保存 `e₁,e₃,e₄`，所以 3 既足够又必要。

<a id="p-9123"></a>
### P-9123｜从数组高端入栈

**知识点：** [K-9110](讲义.md#k-9110)。**考点：** 栈顶下标约定与先后更新。**题型：** 单项选择。**来源：** B007-03 第 23 张第 5 题。

栈存储于 `V[1…n]`，初始栈顶 `top=n+1`；元素 `x` 入栈的正确操作是：

A. `top++; V[top]=x;`；B. `V[top]=x; top++;`；C. `top--; V[top]=x;`；D. `V[top]=x; top--;`。

**解：** 选 C。空栈的 `top=n+1` 指向数组有效范围之外，必须先减到 `n`，再存入元素；入栈前仍须检查是否还有可用空间。

<a id="p-9124"></a>
### P-9124｜摘除链栈栈顶

**知识点：** [K-9110](讲义.md#k-9110)。**考点：** 保存数据和更新栈顶。**题型：** 单项选择。**来源：** B007-03 第 23 张第 6 题。

链栈结点含 `(data,link)`，`top` 指向栈顶。摘除栈顶并将其值存入 `x`，应执行：

A. `x=top->data; top=top->link;`  
B. `top=top->link; x=top->link;`  
C. `x=top; top=top->link;`  
D. `x=top->link;`

**解：** 选 A，先读旧栈顶数据，再将栈顶指向下一结点；操作前须确认栈非空。若该结点为动态分配，完整实现还需用临时指针保存旧结点并释放它。

<a id="p-9125"></a>
### P-9125｜删除链队列的最后一个结点

**知识点：** [K-9112](讲义.md#k-9112)。**考点：** 删除最后一个结点时维护头尾指针。**题型：** 单项选择。**来源：** B007-03 第 24 张第 7 题。

用链接方式存储的队列进行删除运算时：A. 仅修改头指针；B. 仅修改尾指针；C. 头、尾指针都要修改；D. 头、尾指针可能都要修改。

**解：** 选 D。一般出队只改变头部链接或头指针；删除最后一个元素时，还需将尾指针设为该实现的空队状态，例如空指针或头结点。

<a id="p-9126"></a>
### P-9126｜循环数组下标推进

**知识点：** [K-9111](讲义.md#k-9111)。**考点：** 数组下标范围与取模基数。**题型：** 单项选择。**来源：** B007-03 第 24 张第 8 题。

循环队列存储在数组 `A[0…m]` 中，入队时尾指针推进操作是：A. `rear=rear+1`；B. `rear=(rear+1)%(m−1)`；C. `rear=(rear+1)%m`；D. `rear=(rear+1)%(m+1)`。

**解：** 选 D。`0…m` 一共有 `m+1` 个存储单元，前进到末尾后要对 `m+1` 取模；入队前另需依该实现判断队满。

<a id="p-9127"></a>
### P-9127｜循环队列的空队条件

**知识点：** [K-9111](讲义.md#k-9111)。**考点：** 留空一格时的空队与容量口径。**题型：** 单项选择。**来源：** B007-03 第 25 张第 9 题。

“最大容量为 `n` 的循环队列，队尾指针是 `rear`、队头是 `front`，则队空条件是”：A. `(rear+1)%n==front`；B. `rear==front`；C. `rear+1==front`；D. `(rear−1)%n==front`。

**解：** 按课件“数组有 `n` 个单元、留一个空位，`front` 指队头、`rear` 指尾后位置”的约定选 B；A 是满队条件，可实际存储 `n−1` 个元素。原题“最大容量为 n”没有区分数组单元数与有效容量；如果 `n` 表示可容纳的元素个数，还需明确采用的存储和标志方案。

<a id="p-9128"></a>
### P-9128｜栈与队列的共同点

**知识点：** [K-9109](讲义.md#k-9109)。**考点：** 端点操作限制。**题型：** 单项选择。**来源：** B007-03 第 25 张第 10 题。

栈和队列的共同点是：A. 都是先进先出；B. 都是先进后出；C. 只允许在端点处插入和删除元素；D. 没有共同点。

**解：** 选 C。栈在同一端插入、删除；队列从一端插入、另一端删除，二者都限制在表的端点操作，但出入顺序不同。

## 串、数组与广义表

<a id="p-9129"></a>
### P-9129｜串的特殊性

**知识点：** [K-9113](讲义.md#k-9113)。**考点：** 串与一般线性表的区别。**题型：** 单项选择。**来源：** B007-04 第 18 张第 1 题。

串是一种特殊的线性表，其特殊性体现在：A. 可以顺序存储；B. 数据元素是一个字符；C. 可以链式存储；D. 数据元素可以是多个字符。

**解：** 选 B。串的逻辑元素限定为字符；顺序与链式只是可能的存储方式，一个块链结点可容纳多个字符不改变逻辑元素是字符。

<a id="p-9130"></a>
### P-9130｜串的长度

**知识点：** [K-9113](讲义.md#k-9113)。**考点：** 字符数与空格。**题型：** 单项选择。**来源：** B007-04 第 18 张第 2 题。

串的长度是指：A. 不同字母的个数；B. 字符的个数；C. 不同字符的个数；D. 非空格字符的个数。

**解：** 选 B。每个字符都按位置计数，重复字符和空格也计入；用于结束 C 字符串的 `\0` 不计入串长。

<a id="p-9131"></a>
### P-9131｜行优先地址

**知识点：** [K-9114](讲义.md#k-9114)。**考点：** 从非零下标计算行优先偏移。**题型：** 单项选择。**来源：** B007-04 第 19 张第 3 题。

二维数组 `A[1…100,1…100]` 以行优先存储，每个元素占 2 个存储单元，首地址为 10。`LOC[5,5]` 是：A. 808；B. 818；C. 1010；D. 1020。

**解：** 选 B。元素偏移 `(5−1)×100+(5−1)=404`，地址为 `10+404×2=818`。

<a id="p-9132"></a>
### P-9132｜列优先地址

**知识点：** [K-9114](讲义.md#k-9114)。**考点：** 按列优先计算偏移。**题型：** 单项选择。**来源：** B007-04 第 19 张第 4 题。

数组 `A[i,j]` 的行下标为 1 至 8、列下标为 1 至 10，每个元素占 3 字节，从地址 `BA` 开始按列优先存放。`A[5,8]` 的地址是：A. `BA+141`；B. `BA+180`；C. `BA+222`；D. `BA+225`。

**解：** 选 B。前 7 列共有 `7×8` 个元素，本列中前面 4 个，偏移共 60 个元素，地址为 `BA+60×3=BA+180`。

<a id="p-9133"></a>
### P-9133｜行优先与列优先的相同地址

**知识点：** [K-9114](讲义.md#k-9114)。**考点：** 元素偏移和字节偏移的换算。**题型：** 单项选择。**来源：** B007-04 第 20 张第 5 题。

二维数组 `A` 的每个元素是由 10 个字符组成的串，行下标 `0…8`、列下标 `1…10`，每字符占 1 字节。按行优先存储时，`A[8,5]` 的起始地址，与按列优先存储时哪个元素的起始地址相同？A. `A[8,5]`；B. `A[3,10]`；C. `A[5,8]`；D. `A[0,9]`。

**解：** 选 B。按行优先，`A[8,5]` 的元素偏移为 `8×10+(5−1)=84`；按列优先，`A[3,10]` 的元素偏移为 `(10−1)×9+3=84`。每个元素占 10 字节，两者实际地址都是 `BA+840`；原解写 `BA+84`，漏乘元素大小。

<a id="p-9134"></a>
### P-9134｜嵌套表头与表尾

**知识点：** [K-9116](讲义.md#k-9116)。**考点：** 由内到外执行 Head 和 Tail。**题型：** 单项选择。**来源：** B007-04 第 20 张第 6 题。

设 `A=(a,b,(c,d),(e,(f,g)))`，`Head(Tail(Head(Tail(Tail(A)))))` 的值是：A. `(g)`；B. `(d)`；C. `c`；D. `d`。

**解：** 选 D。`Tail(Tail(A))=((c,d),(e,(f,g)))`，对其取头得 `(c,d)`，再取尾得 `(d)`，最后取头得原子 `d`。

<a id="p-9135"></a>
### P-9135｜对称矩阵压缩地址

**知识点：** [K-9115](讲义.md#k-9115)。**考点：** 下三角行优先位序。**题型：** 单项选择。**来源：** B007-04 第 21 张第 7 题。

10 阶对称矩阵按行优先压缩存储，`a₁₁` 是第一元素、地址为 1，每元素占一个地址空间；`a₈₅` 的地址是：A. 13；B. 32；C. 33；D. 40。

**解：** 课件选 C，但题面未说明保留哪一半。按保留含对角线的下三角、按行存储的约定，`a₈₅` 的位序为 `8×7/2+5=33`，地址为 33。

<a id="p-9136"></a>
### P-9136｜对称矩阵上三角元素的定位

**知识点：** [K-9115](讲义.md#k-9115)。**考点：** 利用对称性定位下三角。**题型：** 单项选择。**来源：** B007-04 第 21 张第 8 题。

`n` 阶对称矩阵按行将下三角含对角线存入一维数组 `B[1…n(n+1)/2]`。当 `i<j`，元素 `aᵢⱼ` 在 `B` 中的位置 `k` 为：

A. `i(i−1)/2+j`；B. `j(j−1)/2+i`；C. `i(i+1)/2+j`；D. `j(j+1)/2+i`。

**解：** 选 B。`aᵢⱼ=aⱼᵢ`，后者位于第 `j` 行下三角的第 `i` 个位置；前面共有 `j(j−1)/2` 个元素。

<a id="p-9137"></a>
### P-9137｜三维数组的元素个数

**知识点：** [K-9114](讲义.md#k-9114)。**考点：** 各维下标个数相乘。**题型：** 单项选择。**来源：** B007-04 第 22 张第 9 题。

数组 `A[0…4, −1…−3, 5…7]` 有多少元素？A. 55；B. 45；C. 36；D. 16。

**解：** 课件选 B：第一维有 5 个，第二维按 `−1、−2、−3` 共 3 个理解，第三维有 3 个，乘积为 `5×3×3=45`。原题第二维从 −1 写到 −3，不符合通常按升序写上下界的记法；若要求严格升序，应将其更明确写成 `−3…−1`。

<a id="p-9138"></a>
### P-9138｜含一个子表的表头与表尾

**知识点：** [K-9116](讲义.md#k-9116)。**考点：** 区分原子、子表与空表。**题型：** 双空选择。**来源：** B007-04 第 22 张第 10 题。

广义表 `((a,b,c,d))` 的表头和表尾分别是什么？选项：A. `a`；B. `()`；C. `(a,b,c,d)`；D. `(b,c,d)`。

**解：** 表头选 C，表尾选 B。原表的唯一顶层元素是子表 `(a,b,c,d)`；移除它后剩余空表 `()`。

<a id="p-9139"></a>
### P-9139｜广义表的长度与深度

**知识点：** [K-9116](讲义.md#k-9116)。**考点：** 顶层元素数与嵌套层数。**题型：** 单项选择。**来源：** B007-04 第 22 张第 11 题。

广义表 `L=((a,b,c))` 的长度和深度分别为：A. 1 和 1；B. 1 和 3；C. 1 和 2；D. 2 和 3。

**解：** 选 C。顶层只有一个子表，所以长度为 1；最深元素位于两层括号中，所以深度为 2。

<a id="p-9140"></a>
### P-9140｜混合原子与子表的长度与深度

**知识点：** [K-9116](讲义.md#k-9116)。**考点：** 只数顶层元素并找最深嵌套。**题型：** 填空。**来源：** B007-04 第 14 张。

广义表 `(a,(a,b),d,e,((i,j),k))` 的长度和深度分别是多少？

**解：** 长度为 5：顶层依次是 `a`、`(a,b)`、`d`、`e`、`((i,j),k)`；深度为 3：元素 `i、j` 分别位于三层括号内。空表应单独处理，不能直接套用“顶层逗号数加一”。
