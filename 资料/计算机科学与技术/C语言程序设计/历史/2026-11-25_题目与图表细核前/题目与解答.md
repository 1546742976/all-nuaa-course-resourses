## 基础语句与运算

<a id="p-9001"></a>
### P-9001｜米老鼠偷糖果

**知识点：** K-9002 算术运算。**考点：** 根据总数、每次数量和次数写表达式。**题型：** 编程。**来源：** B003-02 第 3 页。

有 `n` 颗糖，每次拿走 `a` 颗，共拿 `x` 次，假设拿完后仍有糖。输入三个整数 `n a x`，输出剩余数量。样例：`12 2 3` → `6`。

**解：** 一共拿走 `a*x`，所以剩下 `n-a*x`。

```c
int n, a, x;
scanf("%d%d%d", &n, &a, &x);
printf("%d\n", n - a * x);
```

<a id="p-9002"></a>
### P-9002｜时钟旋转

**知识点：** K-9002 算术运算。**考点：** 时针每小时转 30°。**题型：** 编程。**来源：** B003-02 第 4 页。

时针从 `m` 时转到 `n` 时，`m≤n`，二者都是 1 至 12 的整数。输入 `m n`，输出转过的度数。样例：`1 4` → `90`。

**解：** 表盘一圈 360° 分成 12 份，每小时 30°，因此输出 `(n-m)*30`。

```c
int m, n;
scanf("%d%d", &m, &n);
printf("%d\n", (n - m) * 30);
```

<a id="p-9003"></a>
### P-9003｜挖胡萝卜

**知识点：** K-9002 算术与浮点除法。**考点：** 由倍数和差求数量，保留一位小数。**题型：** 编程。**来源：** B003-02 第 5 页。

小兔挖了 `x` 个胡萝卜，狐狸挖的是小兔的 3 倍，小羊比狐狸少 8 个。输入整数 `x`，分别输出狐狸数量、小羊数量和三只动物的平均数量，每行一个，平均数保留一位小数。样例：输入 `10`，依次输出 `30`、`22`、`20.7`。

**解：** 设狐狸 `y=3*x`，小羊 `z=y-8`；平均数除以 `3.0`，避免整数除法截断。

```c
int x, y, z;
scanf("%d", &x);
y = 3 * x; z = y - 8;
printf("%d\n%d\n%.1f\n", y, z, (x + y + z) / 3.0);
```

<a id="p-9004"></a>
### P-9004｜百位与个位对调

**知识点：** K-9002 整除与取余。**考点：** 分离并重组十进制数位。**题型：** 编程。**来源：** B003-02 第 6 页。

输入三位自然数 `x`（`100≤x≤999`），把百位与个位对调，输出得到的整数。样例：`123` → `321`。

**解：** 百位 `x/100`，十位 `x/10%10`，个位 `x%10`。新数为 `个位*100+十位*10+百位`；个位为 0 时按整数输出，不保留前导零。

```c
int x;
scanf("%d", &x);
printf("%d\n", (x % 10) * 100 + (x / 10 % 10) * 10 + x / 100);
```

### P-9005｜晨练温度

**知识点：** K-9003 条件判断。**考点：** 闭区间判断。**题型：** 编程。**来源：** B003-02 第 7 页。

输入整数温度 `t`；当 `20≤t≤30` 时输出 `OK`，否则输出 `NO`。样例：`22` → `OK`。

**解：** 两个边界都包含，用 `t >= 20 && t <= 30`，不能写成数学形式的 `20 <= t <= 30`。

```c
int t;
scanf("%d", &t);
if (t >= 20 && t <= 30) puts("OK");
else puts("NO");
```

<a id="p-9006"></a>
### P-9006｜四数最大值

**知识点：** K-9003 分支。**考点：** 依次比较并更新最大值。**题型：** 编程。**来源：** B003-02 第 8 页。

输入一行四个互不相等的整数，以空格分隔，输出其中最大数并换行。样例：`1 9 8 6` → `9`。

**解：** 用第一个输入初始化最大值，再依次比较剩余三个；这样四个数全为负数时也正确。原材料写 `max=-1`，对小于 −1 的输入不成立。

```c
int x, max;
scanf("%d", &max);
for (int i = 1; i < 4; ++i) {
    scanf("%d", &x);
    if (x > max) max = x;
}
printf("%d\n", max);
```

### P-9007｜需要几辆车

**知识点：** K-9002 整除与取余。**考点：** 向上取整。**题型：** 编程。**来源：** B003-02 第 9 页。

学校有 `n` 名学生，每辆大巴可坐 30 人。输入一个整数 `n`，输出需要的大巴数量。样例：`18` → `1`。

**解：** 先求完整的 30 人组，若有余数再加一辆；人数按题意为非负整数。

```c
int n;
scanf("%d", &n);
printf("%d\n", n / 30 + (n % 30 != 0));
```

### P-9008｜闰年判断

**知识点：** K-9003 逻辑表达式。**考点：** 能被 4 整除但不能被 100 整除，或能被 400 整除。**题型：** 编程。**来源：** B003-02 第 10 页。

输入一个表示年份的四位整数，是闰年输出 `yes`，否则输出 `no`。样例：`1996` → `yes`。

**解：** 这两个条件满足任一个即可；例如 1900 不满足，2000 满足。

```c
int y;
scanf("%d", &y);
if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) puts("yes");
else puts("no");
```

<a id="p-9009"></a>
### P-9009｜苹果和虫子

**知识点：** K-9002 整数运算与 K-9003 分支。**考点：** 向上取整并限制剩余数量。**题型：** 编程。**来源：** B003-02 第 11 页。

一箱有 `n` 个苹果，虫子每 `x` 小时吃掉一个，吃完一个才吃下一个。输入整数 `n x y`，输出经过 `y` 小时后仍完整的苹果数。样例：`10 4 9` → `7`。

**解：** 开始啃的苹果也不完整，故受影响数为 `y/x + (y%x != 0)`；结果不能小于 0。这里按题意 `x>0，n、y≥0`。

```c
int n, x, y;
scanf("%d%d%d", &n, &x, &y);
int remaining = n - y / x - (y % x != 0);
printf("%d\n", remaining > 0 ? remaining : 0);
```

### P-9010｜筛选并输出整数

**知识点：** K-9004 循环。**考点：** 组合整除条件。**题型：** 编程。**来源：** B003-02 第 12 页。

输入整数 `n`，输出从 1 到 `n` 中是 2 的倍数、但不是 3 的倍数的数，每行一个。样例输入 `10`，输出依次为 `2`、`4`、`8`、`10`。

**解：** 逐个枚举，用余数同时判断两个条件。

```c
int n;
scanf("%d", &n);
for (int i = 1; i <= n; ++i)
    if (i % 2 == 0 && i % 3 != 0) printf("%d\n", i);
```

### P-9011｜最大跨度值

**知识点：** K-9004 循环与比较。**考点：** 一遍输入求最大值和最小值。**题型：** 编程。**来源：** B003-02 第 13 页。

给定长度为 `n` 的非负整数序列，跨度为最大值减最小值。第一行输入 `n`（`1≤n≤1000`），第二行输入 `n` 个不超过 1000 的非负整数，空格分隔；输出跨度。样例：`6`，下一行 `3 0 8 7 5 9` → `9`。

**解：** 第一个数同时初始化最大值和最小值，依次更新，最后相减。

```c
int n, x, lo, hi;
scanf("%d%d", &n, &x);
lo = hi = x;
for (int i = 1; i < n; ++i) {
    scanf("%d", &x);
    if (x < lo) lo = x;
    if (x > hi) hi = x;
}
printf("%d\n", hi - lo);
```

<a id="p-9012"></a>
### P-9012｜数据分析

**知识点：** K-9004 循环与数位拆分。**考点：** 统计十进制位数与偶数数位之和。**题型：** 编程。**来源：** B003-02 第 14 页。

输入一个至多 10 位的整数，输出它的十进制位数以及各偶数数位之和，以空格分隔。样例：`12345678` → `8 20`。原题未说明负数和 0 的口径；以下按非负整数处理，0 按一位计。

**解：** 每次用 `%10` 取末位、`/10` 去掉末位；使用 `do...while` 使输入 0 也计一位，十位数使用 `unsigned long long` 存储。

```c
unsigned long long n;
int count = 0, sum = 0;
scanf("%llu", &n);
do {
    int digit = (int)(n % 10);
    ++count;
    if (digit % 2 == 0) sum += digit;
    n /= 10;
} while (n != 0);
printf("%d %d\n", count, sum);
```

### P-9013｜斐波那契数列

**知识点：** K-9004 循环与递推。**考点：** 保存前两项并更新。**题型：** 编程。**来源：** B003-02 第 15 页。

数列前两项都是 1，以后每项等于前两项之和。输入正整数 `k`（`1≤k≤46`），输出第 `k` 项。样例：`19` → `4181`。

**解：** 初始 `a=b=1`，从第 3 项开始反复更新；第 1、2 项直接输出 1。

```c
int k, a = 1, b = 1;
scanf("%d", &k);
for (int i = 3; i <= k; ++i) {
    int next = a + b;
    a = b; b = next;
}
printf("%d\n", b);
```

### P-9014｜与 7 无关的数

**知识点：** K-9004 循环与数位判断。**考点：** 同时排除 7 的倍数和数位含 7 的数。**题型：** 编程。**来源：** B003-02 第 16 页。

能被 7 整除，或者十进制某一位是 7 的正整数称为与 7 有关。输入正整数 `n`（`n<100`），输出不大于 `n` 的所有与 7 无关的正整数的平方和。样例：`21` → `2336`。

**解：** 枚举 1 至 `n`；因为不足 100，个位、十位分别用 `%10` 和 `/10` 检查，满足条件才累计平方。

```c
int n, sum = 0;
scanf("%d", &n);
for (int i = 1; i <= n; ++i)
    if (i % 7 != 0 && i % 10 != 7 && i / 10 != 7) sum += i * i;
printf("%d\n", sum);
```

<a id="p-9015"></a>
### P-9015｜金币

**知识点：** K-9004 循环。**考点：** 按阶段计数。**题型：** 编程。**来源：** B003-02 第 17 页。

骑士第 1 天收 1 枚金币，之后连续 2 天每天收 2 枚，再连续 3 天每天收 3 枚，以此类推。输入天数 `n`（1 至 10000），输出从第 1 天起获得的金币总数。样例：`6` → `14`。

**解：** 第 `k` 阶段有 `k` 天，每天 `k` 枚；逐天累计，达到 `n` 天时停下。

```c
int n, day = 0, sum = 0;
scanf("%d", &n);
for (int k = 1; day < n; ++k)
    for (int j = 0; j < k && day < n; ++j) {
        sum += k;
        ++day;
    }
printf("%d\n", sum);
```

### P-9016｜陶陶摘苹果

**知识点：** K-9006 一维数组。**考点：** 遍历并计数。**题型：** 编程。**来源：** B003-02 第 18—19 页。

第一行给出 10 个苹果离地高度（100 至 200 厘米）；第二行给出陶陶伸直手能达到的高度（100 至 120 厘米）。她可以站在 30 厘米高的板凳上，碰到苹果就能摘下。输出能摘到的苹果数。样例：高度 `100 200 150 140 129 134 167 198 200 111`，伸手高度 `110`，输出 `5`。

**解：** 把 10 个高度存入数组，逐个判断是否小于等于 `手高+30`；原代码展示了相同的比较和计数。

```c
int a[10], reach, count = 0;
for (int i = 0; i < 10; ++i) scanf("%d", &a[i]);
scanf("%d", &reach);
for (int i = 0; i < 10; ++i)
    if (a[i] <= reach + 30) ++count;
printf("%d\n", count);
```

<a id="p-9017"></a>
### P-9017｜排除异形基因

**知识点：** K-9006 数组遍历。**考点：** 保留符合条件的序列元素及其顺序。**题型：** 编程。**来源：** B003-02 第 20—21 页。

输入基因个数 `n`（`3≤n≤200`）及随后 `n` 个整数；如果某个数的平方除以 7 余 1，就将其排除。按原顺序输出其余数，用空格分隔。样例：`4`，下一行 `6 2 8 12` → `2 12`。

**解：** 因为平方余数只与原数除以 7 的余数有关，先取余再平方，避免原数较大时直接平方溢出。原图代码使用 `a[i]*a[i]%7`。

```c
int n, x, first = 1;
scanf("%d", &n);
for (int i = 0; i < n; ++i) {
    scanf("%d", &x);
    int r = x % 7;
    if (r * r % 7 != 1) {
        if (!first) putchar(' ');
        printf("%d", x);
        first = 0;
    }
}
putchar('\n');
```

### P-9018｜取到某个数字的概率

**知识点：** K-9006 数组与统计。**考点：** 频数除以总数，保留两位小数。**题型：** 编程。**来源：** B003-02 第 22—23 页。

袋中有 `n` 个球（`n≤100`），每个球上有一个数字，随机取一个。输入三行：球数 `n`、`n` 个球上的数字、要查询的数字 `x`；`x` 可以没出现。输出取到 `x` 的概率，保留两位小数。样例：`5`、`2 3 2 4 2`、`2` → `0.60`。

**解：** 用数组保存输入，待读到 `x` 后遍历计数并除以 `n`。袋中有球时 `n>0`；原图用数字作数组下标，但题面没给数字范围，直接比较不依赖下标范围。

```c
int n, a[100], x, count = 0;
scanf("%d", &n);
for (int i = 0; i < n; ++i) scanf("%d", &a[i]);
scanf("%d", &x);
for (int i = 0; i < n; ++i) if (a[i] == x) ++count;
printf("%.2f\n", (double)count / n);
```

### P-9019｜杨辉三角

**知识点：** K-9007 二维数组。**考点：** 边界赋 1，内部由上一行相邻元素相加。**题型：** 编程。**来源：** B003-02 第 24—25 页。

输入整数 `N`（原题给出 `N<10`），输出杨辉三角前 `N` 行。样例输入 `5`，依次输出 `1`、`1 1`、`1 2 1`、`1 3 3 1`、`1 4 6 4 1`。按题意取 `N≥1`。

**解：** 每行两端是 1，其他位置为上一行左上与右上之和。

```c
int n, a[10][10] = {{0}};
scanf("%d", &n);
for (int i = 0; i < n; ++i) {
    for (int j = 0; j <= i; ++j) {
        a[i][j] = (j == 0 || j == i) ? 1 : a[i-1][j-1] + a[i-1][j];
        if (j) putchar(' ');
        printf("%d", a[i][j]);
    }
    putchar('\n');
}
```

## 字符数组和字符串

### P-9020｜基因相关性

**知识点：** K-9008 字符串遍历。**考点：** 统计相同位置的字符比例并处理相等边界。**题型：** 编程。**来源：** B003-02 第 26—27 页。

输入阈值和两条等长 DNA 字符串（长度不超过 500），逐位比较；相同位置所占比例大于等于阈值时输出 `yes`，否则输出 `no`。样例给定阈值 `0.85`，两条序列分别为 `ATCGCCGTAAGTAACGGTTTTAAATAGGCC` 和 `ATCGCCGGAAGTAACGGTCTTAAATAGGCC`，输出 `yes`。

**解：** 依次统计相等位置，除以序列长度，再与阈值比较。原示例代码使用严格大于 `>`，与题面“大于等于”不一致；循环下标用 `int` 避免 `char` 无法遍历 500 位。需另外包含 `<string.h>`。

```c
double threshold;
char a[501], b[501];
int same = 0;
scanf("%lf%500s%500s", &threshold, a, b);
int len = (int)strlen(a);
for (int i = 0; i < len; ++i) if (a[i] == b[i]) ++same;
puts((double)same / len >= threshold ? "yes" : "no");
```

<a id="p-9021"></a>
### P-9021｜合法标识符

**知识点：** K-9001 标识符与 K-9008 字符串。**考点：** 判断首字符和后续字符。**题型：** 编程。**来源：** B003-02 第 28—29 页。

输入不含空白、长度不超过 20 的字符串，题目保证它不是 C 保留字。按题目给定规则，合法标识符只含英文字母、数字和下划线，且不以数字开头；合法输出 `yes`，否则 `no`。样例：`RKPEGX9R;TWyYcp` → `no`。

**解：** 首字符要求英文字母或下划线；其余字符再允许数字。原图代码把大写字母下界误写为 `'Z'`，并缺少字符串函数头文件。

```c
char s[21];
int ok = 1;
scanf("%20s", s);
if (!((s[0] >= 'A' && s[0] <= 'Z') ||
      (s[0] >= 'a' && s[0] <= 'z') || s[0] == '_')) ok = 0;
for (int i = 1; s[i] != '\0'; ++i)
    if (!((s[i] >= 'A' && s[i] <= 'Z') ||
          (s[i] >= 'a' && s[i] <= 'z') ||
          (s[i] >= '0' && s[i] <= '9') || s[i] == '_')) ok = 0;
puts(ok ? "yes" : "no");
```

<a id="p-9022"></a>
### P-9022｜配对碱基链

**知识点：** K-9008 字符串。**考点：** 遍历和字符映射。**题型：** 编程。**来源：** B003-02 第 30—31 页。

输入一条只由大写 `A、T、G、C` 构成的 DNA 碱基链，长度不超过 255；输出按相同位置配对的互补链，规则为 `A↔T`、`G↔C`。样例：`ATATGGATGGTGTTTGGCTCTG` → `TATACCTACCACAAACCGAGAC`。

**解：** 按原顺序逐字符查规则并输出，最后换行。

```c
char s[256];
scanf("%255s", s);
for (int i = 0; s[i] != '\0'; ++i) {
    char c = s[i];
    putchar(c == 'A' ? 'T' : c == 'T' ? 'A' : c == 'C' ? 'G' : 'C');
}
putchar('\n');
```

<a id="p-9023"></a>
### P-9023｜出现次数最多的小写字母

**知识点：** K-9006 数组与 K-9008 字符串。**考点：** 频数统计及并列规则。**题型：** 编程。**来源：** B003-02 第 32—33 页。

输入由小写字母组成、长度不超过 100 的字符串，输出出现次数最多的字母；并列时输出 ASCII 值最大的字母。原样例：`aaabbbbbbbbcdxs` → `b`。

**解：** 以 `字母-'a'` 作为下标统计，再从 `a` 到 `z` 扫描；出现次数相等也更新，最终留下较大的字母。数组必须留一格给字符串结束符。

```c
char s[101];
int count[26] = {0}, best = 0;
scanf("%100s", s);
for (int i = 0; s[i] != '\0'; ++i) ++count[s[i] - 'a'];
for (int i = 1; i < 26; ++i)
    if (count[i] >= count[best]) best = i;
printf("%c\n", 'a' + best);
```

### P-9024｜判断素数

**知识点：** K-9005 函数。**考点：** 小于 2 的边界及试除终点。**题型：** 编程。**来源：** B003-02 第 34—35 页。

输入一个整数，是素数输出 `T`，否则输出 `F`。素数为大于 1 且只有 1 和自身两个正因数的自然数。样例：`57` → `F`。

**解：** 小于 2 直接判否；否则从 2 试除到平方根。用 `d <= x/d` 避免 `d*d` 溢出。下面是完整程序；原图未单独排除 0、1 和负数。

```c
#include <stdio.h>
int is_prime(int x) {
    if (x < 2) return 0;
    for (int d = 2; d <= x / d; ++d)
        if (x % d == 0) return 0;
    return 1;
}
int main(void) {
    int n;
    scanf("%d", &n);
    puts(is_prime(n) ? "T" : "F");
    return 0;
}
```

### P-9025｜两位绝对素数

**知识点：** K-9005 函数复用。**考点：** 数位交换与两次素数判断。**题型：** 编程。**来源：** B003-02 第 36—37 页。

如果一个两位数是素数，交换它的两个数位后仍为素数，称其为绝对素数。无需输入，按从小到大顺序每行输出一个两位绝对素数。

**解：** 复用 P-9024 的 `is_prime` 函数，在 `main` 中枚举 10 至 99；交换结果为 `(n%10)*10+n/10`。结果为 `11、13、17、31、37、71、73、79、97`，每数一行。

```c
for (int n = 10; n <= 99; ++n) {
    int reversed = n % 10 * 10 + n / 10;
    if (is_prime(n) && is_prime(reversed)) printf("%d\n", n);
}
```

### P-9026｜三个数的最大值函数

**知识点：** K-9005 函数参数与返回值。**考点：** 把三数求最大值封装为函数。**题型：** 编程。**来源：** B003-02 第 38—39 页。

输入 `a、b、c`，计算 `m=max(a,b,c)/(max(a+b,b,c)×max(a,b,b+c))`，输出保留三位小数；求三个数的最大值定义为函数。样例：`1 2 3` → `0.200`。题面未指定分母为零时的结果，以下解法适用于分母非零的输入。

**解：** 写一个返回三数最大值的函数，分别求分子和两个分母因子。以下为完整程序。

```c
#include <stdio.h>
double max3(double x, double y, double z) {
    double m = x > y ? x : y;
    return m > z ? m : z;
}
int main(void) {
    double a, b, c;
    scanf("%lf%lf%lf", &a, &b, &c);
    double denominator = max3(a + b, b, c) * max3(a, b, b + c);
    if (denominator != 0) printf("%.3f\n", max3(a, b, c) / denominator);
    return 0;
}
```

### P-9027｜阿克曼函数

**知识点：** K-9005 递归。**考点：** 分段递推、调用增长及边界。**题型：** 编程。**来源：** B003-02 第 40—41 页。

非负整数 `m≤3、n≤10`，定义：`A(0,n)=n+1`；`m>0,n=0` 时 `A(m,n)=A(m-1,1)`；`m>0,n>0` 时 `A(m,n)=A(m-1,A(m,n-1))`。输入 `m n`，输出函数值。样例：`2 3` → `9`。

**解：** 可按定义递归，但 `A(3,10)` 会产生大量调用和很深的调用栈。由递推分别得到 `A(1,n)=n+2`、`A(2,n)=2n+3`、`A(3,n)=2^(n+3)-3`，在本题范围直接计算。原图给出递归写法，未讨论调用深度。

```c
int m, n, value;
scanf("%d%d", &m, &n);
if (m == 0) value = n + 1;
else if (m == 1) value = n + 2;
else if (m == 2) value = 2 * n + 3;
else value = (1 << (n + 3)) - 3;
printf("%d\n", value);
```

### P-9028｜输入若干数求最大值

**知识点：** K-9004 循环与比较。**考点：** 从输入初始化最大值。**题型：** 编程。**来源：** B003-01 第 38 张。

先输入数据个数，再输入这些整数，输出最大值。课件样例：`5`，下一行 `1 3 50 -5 0` → `50`。按题意至少输入一个数。

**解：** 先读取第一个数作为当前最大值，再读取其余数并比较。课件代码以 0 初始化，不能处理全为负数的输入；本解法修正这一点，也不需要保存整个数组。

```c
int n, x, max;
scanf("%d%d", &n, &max);
for (int i = 1; i < n; ++i) {
    scanf("%d", &x);
    if (x > max) max = x;
}
printf("%d\n", max);
```

### P-9029｜输出 101 至 200 的素数

**知识点：** K-9004 循环与 K-9005 函数。**考点：** 试除法及平方根边界。**题型：** 编程。**来源：** B003-01 第 39 张。

找出 101 至 200 之间的素数并输出，课件示例每输出 6 个数换行。

**解：** 复用 P-9024 的 `is_prime`，依次判断每个数。原代码循环条件 `j*j<i` 漏掉平方根本身，可能把完全平方数误判为素数；这里使用已包含边界的函数。

```c
int count = 0;
for (int n = 101; n <= 200; ++n) {
    if (is_prime(n)) {
        printf("%d", n);
        ++count;
        putchar(count % 6 == 0 ? '\n' : ' ');
    }
}
if (count % 6 != 0) putchar('\n');
```

### P-9030｜用指针交换三个数

**知识点：** K-9005 传址与 K-9009 指针。**考点：** 交换函数与三次比较。**题型：** 编程。**来源：** B003-01 第 40 张。

输入三个整数，使用指针方法将它们从小到大输出。样例：`9 4 7` → `4 7 9`。

**解：** `swap` 接收两个变量的地址，通过解引用交换对应的值。依次比较 `a,b`、`b,c`、`a,b`，三次比较后得到升序。以下是完整程序。

```c
#include <stdio.h>
void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
int main(void) {
    int a, b, c;
    scanf("%d%d%d", &a, &b, &c);
    if (a > b) swap(&a, &b);
    if (b > c) swap(&b, &c);
    if (a > b) swap(&a, &b);
    printf("%d %d %d\n", a, b, c);
    return 0;
}
```

### P-9031｜三名学生的成绩

**知识点：** K-9010 结构体数组。**考点：** 按成员读取数据并计算平均值。**题型：** 编程。**来源：** B003-01 第 41 张。

输入三名学生，每行包含学号、姓名和两门课程成绩。课件题干写“三个学生两门课程总平均成绩”，但样例分别输出每名学生两门课的平均分；以下按样例实现。样例输入：

```text
1234 John 85.5 90.5
1235 Mike 95.5 87.5
1236 Lisa 80.2 96.0
```

样例输出依次为 `John 88.00`、`Mike 91.50`、`Lisa 88.10`，每行一个。若题目要求全体六个成绩的总平均，应先累加六项再除以 6，不能把两种口径混为一谈。

**解：** 以结构体存学号、姓名、两门成绩，逐条读入并计算 `(score1+score2)/2.0`。输入长度限制在 31 个字符以内，为结束符预留空间。

```c
struct Student { int id; char name[32]; double score1, score2; } s[3];
for (int i = 0; i < 3; ++i)
    scanf("%d%31s%lf%lf", &s[i].id, s[i].name, &s[i].score1, &s[i].score2);
for (int i = 0; i < 3; ++i)
    printf("%s %.2f\n", s[i].name, (s[i].score1 + s[i].score2) / 2.0);
```
