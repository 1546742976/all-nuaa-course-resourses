### K-9001｜程序、变量与数据类型

**从问题出发。** 人看见“先读年龄，再输出年龄”能自行补全细节；计算机只会执行明确的指令。C 程序由函数组成，通常从 `main` 开始执行。下面把输入、输出和退出串起来：

```c
#include <stdio.h>
int main(void) {
    int age;
    scanf("%d", &age);
    printf("年龄：%d\n", age);
    return 0;
}
```

`#include` 引入声明；花括号圈住函数体；分号结束语句；`return 0` 表示正常结束。`//` 表示单行注释，`/* ... */` 表示多行注释。注释供人阅读，不参与程序运算。

**变量像带标签的盒子。** 声明 `int age;` 表示留出一个存放整数的对象，`age=18;` 把值放进去。局部变量在所在块内可见，外层声明的同名对象可被内层遮蔽；文件作用域变量从声明位置起在本文件中可见，跨文件使用还涉及链接和声明。不要读未初始化的自动局部变量。

| 类型 | 常见用途 | 常见大小示例 |
| --- | --- | --- |
| `char` | 字符或小整数 | 1 字节 |
| `short`、`int`、`long`、`long long` | 不同范围的整数 | 常见分别为 2、4、4 或 8、8 字节 |
| `float`、`double` | 单精度、双精度浮点数 | 常见分别为 4、8 字节 |

大小取决于实现，使用 `sizeof` 实测；C 的一字节不必然等于 8 位。`char` 类型是否有符号也取决于实现。课件给出的字节数是常见示例，不是所有平台的保证。

`const int limit=100;` 定义不能通过该名字修改的对象；`#define LIMIT 100` 定义预处理宏。宏定义末尾不要为模仿语句习惯随意加分号，否则分号也会进入替换文本。

**标识符**在本资料习题采用的基础规则下，由字母、数字、下划线组成，首字符不能是数字，也不能使用关键字；如 `total_1` 合法而 `1total` 不合法。实际 C 标准对扩展字符等还有规定，本题只按限定字符集判断。

字符常量如 `'A'` 与字符串字面量如 `"A"` 不同。ASCII 里 `'0'`、`'A'`、`'a'` 分别是 48、65、97，数字和大小写字母各自按顺序排列；ASCII 包含 128 个编码，C 标准并不要求所有执行环境都采用 ASCII。

### K-9002｜进制、运算和输入输出

**进制是同一数量的不同写法。** 例如二进制 `1011` 表示 `1×2³+0×2²+1×2+1=11`；十进制 11 连续除以 2，余数倒序读出 `1011`。二进制每三位对应一位八进制、每四位对应一位十六进制，不足位在左边补 0。转换的是表示方法，数值不变。课件示例为十进制 156 = 二进制 10011100 = 八进制 234 = 十六进制 9C。

`+ - * / %` 分别用于加、减、乘、除、取余。整数相除会截去小数部分：`7/2` 得 3；写成 `7/2.0` 才得到 3.5。除数不能为 0；`%` 的操作数须为整数。比较用 `== != < > <= >=`，结果是整数 0 或 1；条件中的任何非零值都视为真。逻辑非 `!`、与 `&&`、或 `||` 按条件组合，后两者具有短路求值行为。

| a | b | a 与 b | a 或 b | 非 a |
| --- | --- | --- | --- | --- |
| 真 | 真 | 真 | 真 | 假 |
| 真 | 假 | 假 | 真 | 假 |
| 假 | 真 | 假 | 真 | 真 |
| 假 | 假 | 假 | 假 | 真 |

**输入是把值放进盒子，输出是把值读出来。** `scanf` 需要目标地址：`scanf("%d", &age)`；`printf("%d", age)` 使用值。常用格式如下：

| 值 | 输出 `printf` | 输入 `scanf` | 说明 |
| --- | --- | --- | --- |
| `int` | `%d` | `%d` | 输入时传 `int *` |
| `unsigned int` | `%u` | `%u` | 无符号整数 |
| `char` | `%c` | `%c` | `%c` 不自动跳过空白，可写 `" %c"` |
| 字符串 | `%s` | `%s` | 输入设置宽度，数组需留结束符 |
| `float` | `%f` | `%f` | `scanf` 接收 `float *` |
| `double` | `%f` | `%lf` | `scanf` 接收 `double *` |

如 `scanf("%20s", name)` 最多读 20 个字符，数组至少需要 21 个元素；`printf("%.2f", value)` 保留两位小数。输入函数的返回值可用来判断成功读取了几个项目。

**例：三位数换位。** `123` 的个位 `123%10=3`，十位 `123/10%10=2`，百位 `123/100=1`，所以交换后是 `3×100+2×10+1=321`。这就是 P-9004 的解题链。

**边学边练：** [P-9001—9004](题目与解答.md#p-9001)、[P-9007](题目与解答.md#p-9007)、[P-9009](题目与解答.md#p-9009)。**三句话带走：** 进制改变写法不改变数值；整数除法和浮点除法不同；输入地址与格式必须匹配。

<a id="k-9003"></a>
### K-9003｜用条件选择路径

**先问问题：** 温度为 20 至 30 度时输出 `OK`，其他情况输出 `NO`。先判断两个边界，再把判断结果交给 `if`：

```c
if (t >= 20 && t <= 30) puts("OK");
else puts("NO");
```

分支链 `if ... else if ... else` 从上到下检查，进入第一个为真的分支。不要写 `20 <= t <= 30`：C 会先计算左侧比较，得到 0 或 1，再与 30 比较。

`switch (grade)` 根据整数类型表达式选择 `case` 标签；每个标签是不同的整数常量表达式。通常用 `break` 结束该分支，否则会继续执行后面的语句；`default` 处理没有匹配标签的情况。条件表达式 `condition ? a : b` 先判断条件，再选择一个值，适合简短选择。

**例：闰年。** 同时满足“被 4 整除且不被 100 整除”，或“被 400 整除”，就输出 `yes`。因此 1900 不是闰年，2000 是。

**边学边练：** [P-9005](题目与解答.md#p-9005)、[P-9006](题目与解答.md#p-9006)、[P-9008](题目与解答.md#p-9008)。**三句话带走：** 条件把执行路径分开；区间要写成两个比较；`switch` 中是否 `break` 会影响后续执行。

### K-9004｜循环、计数和递推

`while` 先判断条件再执行循环体，条件一开始为假就一次也不执行；`do ... while` 先执行再判断，至少执行一次；`for (初始化; 条件; 更新)` 把循环变量的三个关键位置放在一起。

```c
for (int i = 0; i < 5; ++i) printf("%d ", i);  /* 0 1 2 3 4 */
```

循环每走完一轮要检查：状态是否变化？条件是否终会变假？内层循环每完成一次才推进外层一次。例如按阶段发金币，第 `k` 阶段重复 `k` 天，每天加 `k` 枚；已经达到总天数时应立即停止。

**递推不是重新计算全部历史。** 斐波那契数列只需保存前两项 `a、b`；每轮先算 `next=a+b`，再令 `a=b、b=next`。更新顺序不能先覆盖 `a` 再错误使用旧值。求最大值、最小值时用第一个输入作为初值，就不会遗漏全负数或全正数情况。

**边学边练：** [P-9010—9015](题目与解答.md#p-9010)。**三句话带走：** 明确初始化、条件和更新；维护的变量要对应题目状态；检查 0 次、1 次和最后一次循环。

### K-9005｜声明、定义、调用和递归

**为什么用函数？** 同一种判断要在多处使用时，把它写成一个小工具，使用者只需要交出输入、接收结果。例如：

```c
int add(int a, int b);          /* 声明：先告诉编译器接口 */
int add(int a, int b) {         /* 定义：给出具体实现 */
    return a + b;
}
/* 调用：int total = add(2, 3); */
```

`a、b` 是形式参数，`2、3` 是实际参数；调用时将实参的值传给形参。返回类型为 `void` 的函数不返回值；无参数原型使用 `(void)`。函数在调用之前需要有合适的声明或定义。

**函数如何修改调用者的数据？** C 的参数按值传递；传入普通整数时，修改形参不会改原变量。需要修改原变量时，传入其地址，再通过指针访问原对象：

```c
void increment(int *p) { (*p)++; }
/* int n = 5; increment(&n); 此后 n 为 6。 */
```

传入的仍然是地址的副本；通过这个地址修改的是调用者的对象。课件把这种方式称为“传址调用”，不表示 C 有 C++ 式引用参数。

库函数已经提供常用功能：`<stdio.h>` 提供输入输出，`<string.h>` 提供字符串操作，`<math.h>` 提供数学函数，`<stdlib.h>` 提供内存分配等，使用前引入相应声明。自定义函数通过拆分任务减少重复。

课件还展示了这些标准库头文件及其用途；图中的 C++ 写法如 `<cstdio>` 对应 C 的 `<stdio.h>`。

| C 头文件 | 作用 | C 头文件 | 作用 |
| --- | --- | --- | --- |
| `assert.h` | 诊断断言 | `ctype.h` | 字符处理 |
| `errno.h` | 错误码 | `fenv.h` | 浮点环境 |
| `float.h` | 浮点类型特性 | `inttypes.h` | 整数类型格式与工具 |

### K-9006｜一维数组与边界

数组把同类型元素连续排列，像一排从 0 开始编号的盒子。`int a[5] = {10,20,30,40,50};` 有 5 个元素，合法下标为 0 到 4，`a[2]` 是第三个元素，值为 30。

花括号只给部分初值时，剩余元素按初始化规则补零：`int a[5]={1,2};` 得到 `1,2,0,0,0`。`int a[]={1,2,3};` 由初值推断长度。未初始化的自动局部数组不能直接读取。C99 中满足条件的局部可变长数组可使用运行时长度，不必都写成整数常量；变长数组有额外的初始化等限制。

```c
int a[] = {10,20,30,40,50};
size_t n = sizeof a / sizeof a[0];  /* 仅在 a 仍是数组的作用域使用 */
for (size_t i = 0; i < n; ++i) printf("%d ", a[i]);
```

数组传给函数时，数组形参会调整为指针，函数内部 `sizeof` 得到的是指针大小而不是原数组总大小；应额外传入长度。访问 `a[5]` 已越界，不能因为程序没有立刻报错就当成合法。

**例：最大跨度。** 用首元素初始化 `min` 与 `max`，遍历剩余元素并更新，最后输出 `max-min`。一次扫描即可完成。

**边学边练：** [P-9011](题目与解答.md#p-9011)、[P-9016—9018](题目与解答.md#p-9016)。**三句话带走：** 下标从 0 到长度减 1；数组长度和已放入的数据量要分清；越界访问是未定义行为。

<a id="k-9007"></a>
### K-9007｜二维数组与杨辉三角

二维数组可以想成一张按行排放的表：`int a[3][3]={{1,2,3},{4,5,6},{7,8,9}};` 中 `a[1][2]` 是第二行第三列，值为 6。先写行下标，再写列下标。

```text
         列0  列1  列2
行0        1    2    3
行1        4    5    6    ← a[1][2] = 6
行2        7    8    9
```

用嵌套循环先遍历行、再遍历列；二维数组的元素按行连续存放。杨辉三角每行首尾为 1，中间元素等于上一行左上与右上的和，因此可以由上一行逐行生成下一行。

**边学边练：** [P-9019](题目与解答.md#p-9019)。**三句话带走：** 下标对应行和列；嵌套循环逐格处理；递推边界先定好再算内部。

### K-9008｜字符数组、转义与字符串

课件的 `"RUNOOB"` 按索引 0 至 6 依次存放 `R、U、N、O、O、B、\0`。`char s[]="abc";` 实际存放四个字符：`'a'`、`'b'`、`'c'`、`'\0'`。结束符标记字符串在哪结束；`char s[]={'a','b','c'};` 只有三个字符，不是以零结尾的 C 字符串，不能直接交给 `%s`。

`strlen(s)` 统计结束符之前的字符个数，不包括结束符；`sizeof s` 在数组所在作用域统计整个数组占用的字节数，包括结束符。使用字符串库函数需 `#include <string.h>`。

| 写法 | 含义 | 写法 | 含义 |
| --- | --- | --- | --- |
| `\n` | 换行 | `\t` | 水平制表 |
| `\r` | 回车 | `\b` | 退格 |
| `\v` | 垂直制表 | `\f` | 换页 |
| `\a` | 响铃 | `\\` | 反斜杠 |
| `\'` | 单引号 | `\"` | 双引号 |
| `\0` | 空字符 | `\nnn` | 最多三位八进制转义 |

**例：DNA 配对。** 遍历每个字符，把 `A` 换成 `T`、`T` 换成 `A`、`C` 换成 `G`、`G` 换成 `C`。若创建新字符串，末尾也要写入 `\0`；也可以逐字符直接输出。

**边学边练：** [P-9020—9023](题目与解答.md#p-9020)。**三句话带走：** 字符串是以空字符结束的字符序列；空间要包含结束符；输入时限制长度。

**本章复盘**

## 第七章｜指针：把地址作为数据传递

![图 7-1 知识地图](附件/图示/07指针.svg)

图 7-1　指针知识地图。

知识地图：对象 → 取地址 `&` → 指针保存地址 → `*` 访问对象 → 数组与函数。

<a id="k-9009"></a>
### K-9009｜地址、指针、数组和二级指针

把变量想成一间有门牌号的房间：变量保存值，地址指出房间位置，指针变量保存地址。

```c
int age = 5;
int *p = &age;   /* p 保存 age 的地址 */
*p = 6;          /* 通过地址修改 age，age 变成 6 */
printf("%p\n", (void *)&age);
```

声明中的 `*` 表示这是指针；表达式中的 `*p` 解引用，访问所指向的对象。`NULL` 表示空指针，不能解引用；指针必须指向有效对象并满足类型及生命周期要求。用 `%p` 输出对象指针时传 `void *`，地址值依运行环境变化，不应写成固定结果。

`int *p` 与 `double *q` 指向的对象类型不同；`void *` 是通用对象指针，可保存对象地址，但不能直接作为 `void` 对象解引用。在同一数组内 `p+1` 指向下一个 `int` 元素，而不是简单约定增加一个字节。指针可以与整数相加减，同一数组内的两个指针可以相减得到元素间距；两个指针不能相加。指向数组末尾后一位置的指针可用于比较，但不能解引用。

数组名在大多数表达式中转换为首元素指针：`int a[]={1,2,3}; int *p=a;`，于是 `*(p+2)` 等于 `a[2]`。例外包括 `sizeof a` 和 `&a`：前者得到整个数组大小，后者类型为指向整个数组的指针。课件原例用 `printf("%p", arr[0])` 试图打印元素地址，应改为 `(void *)&arr[0]`。

`int **pp=&p;` 保存指针 `p` 自身的地址；`*pp` 得到 `p`，`**pp` 得到 `p` 所指向的整数。在函数中传地址可让函数修改原对象，传指针的地址可以让函数修改原指针。

动态分配示意：`int *a=malloc(n*sizeof *a);` 使用 `<stdlib.h>`，成功后访问所分配范围，最终 `free(a)`；分配失败得到空指针。不要返回指向已结束生命周期的局部变量的指针。

**边学边练：** [P-9030](题目与解答.md#p-9030)。**三句话带走：** 指针保存地址；类型决定解引用和步长；有效范围与生命周期决定能否访问。

## 第八章｜结构体：把不同字段装进一张记录

图 8-1　结构体知识地图。

知识地图：定义类型 → 创建实例 → 初始化成员 → 点号/箭头访问 → 值传递或传地址。

<a id="k-9010"></a>
### K-9010｜结构体与成员访问

一名学生既有姓名又有成绩，类型不同，适合放在同一条结构体记录里：

```c
struct Student { int id; char name[32]; double score1, score2; };
struct Student s = {1234, "John", 85.5, 90.5};
struct Student *p = &s;
printf("%s %.2f\n", s.name, (p->score1 + p->score2) / 2.0);
```

`struct Student` 定义类型，`s` 是一个实例。实例用 `s.score1`，指向实例的指针用 `p->score1`，后者等价于 `(*p).score1`。结构体也可以作为数组元素，逐个记录多名学生。

把整个结构体传入函数会复制该结构体；函数修改副本不会改原对象。传入 `&s` 并通过指针修改成员，才会改变原对象。字符串数组不能用 `=` 整体赋值，可在容量足够时使用 `<string.h>` 的 `strcpy`，输入时用宽度限制，例如 `scanf("%31s", s.name)`。

**边学边练：** [P-9031](题目与解答.md#p-9031)。**三句话带走：** 结构体把不同类型字段组成一条记录；`.` 操作对象、`->` 操作指针所指对象；传副本和传地址的效果不同。
